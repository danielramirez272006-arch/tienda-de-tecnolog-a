# TechStore - Tienda de Tecnología

Tienda de tecnología moderna construida con React y Vite. Catálogo de productos de alto rendimiento con diseño elegante y funcionalidades de carrito de compras.

## Características

- **Diseño Responsivo**: Interfaz adaptada para todos los dispositivos
- **Carrito de Compras**: Sistema completo con drawer lateral
- **Múltiples Páginas**: Inicio, Información, Formulario y Contacto
- **Categorías**: Laptops, Smartphones, Audio
- **Tema Oscuro**: Diseño elegante con paleta de colores copper/minimal

## Tecnologías

- React 19
- Vite
- React Router DOM
- CSS Modules

## Instalación

```bash
cd tecnologia
npm install
npm run dev
```

## Estructura del Proyecto

```
tecnologia/
├── public/          # Imágenes estáticas
├── src/
│   ├── components/  # Componentes reutilizables
│   ├── context/     # Contexto del carrito
│   ├── pages/       # Páginas principales
│   ├── routing/     # Configuración de rutas
│   └── services/    # Datos de la tienda
└── package.json
```
